# 🗂️ Todo App 📋

A responsive Todo App built with HTML, CSS, and JavaScript. It lets you create, update, and delete tasks, and it keeps them saved in your browser using Local Storage.

## ✅ Key Features
- Handle form inputs to add new tasks
- CRUD operations on tasks: **Create, Read, Update, Delete**
- Persist tasks with **Local Storage**
- Event listeners for user interactions
- Toggle UI elements (e.g., show/hide edit mode)

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## ▶️ How to Run
Open `index.html` in your browser.
